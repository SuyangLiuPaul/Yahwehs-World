## Forbidden

- **NIV** or any other copyrighted translation as verse text. The sister
  project had to remove NIV in 2026-05; this one starts clean on BSB.
- **Satellite / aerial imagery** of any provider, including "free" tiles.
  Decision `05-D1`.
- **Fonts without a web licence.** Current fonts are Google Fonts (OFL).
- **Generated imagery that depicts a real modern place photographically** —
  it reintroduces the "landscape that did not exist when the text was written"
  problem. Painterly/illustrative generation is fine with provenance.

## Attribution string (must survive every deployment)

`Place data OpenBible.info · CC BY 4.0 · basemap Natural Earth (public domain)`
(zh: `地名数据 OpenBible.info · CC BY 4.0 · 底图 Natural Earth（公有领域）`)

## Provenance rule for new assets

Any file added under `public/` that is not generated by a script in `scripts/`
gets a row in `MANIFEST-assets.md`: path, what it is, source or generation
prompt + tool, licence, commit. A reviewer must be able to answer "where did
this pixel come from" for every pixel on screen.
