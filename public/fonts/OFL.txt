Every .woff2 file in this directory is a SUBSET of an upstream font: glyphs
the pages never show have been removed and, where the upstream is a variable
font, the weight axis has been clipped and the other axes pinned. Nothing else
is changed — no outline, no name, no metric. The subsets are rebuilt by
`tools/subset-fonts.sh`, which also documents where each original comes from;
`node tools/font-coverage.mjs --check` proves they still cover the shipped text.

All seven families are licensed under the SIL Open Font License, Version 1.1.
That was verified for each one from the licence string in the original's own
name table (name ID 13), not from a web page. The licence is reproduced in
full below.

The sha256 is of the ORIGINAL file that was subset, not of the .woff2 built
from it, so a future build can prove it started from the same bytes.
